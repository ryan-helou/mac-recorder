I take a lot of short calls on Microsoft Teams, and the meeting note taker doesn't always join them. I built Mac Recorder so I can capture those calls myself, on my own computer, without relying on anyone else's tool.

I press one button and it records everything: what is on my screen, the voices of the people I'm talking to, and my own microphone. When I stop, it saves a single video file to my Movies folder and shows it to me in Finder.

I can record my whole screen with all the sound on my Mac, or only the Teams windows and Teams sound. The recording keeps going if I close the app's window, and everything stays on my Mac. Nothing is uploaded anywhere.

## Get it

Download this repository, run `./build.sh --install` in the folder, then open Mac Recorder from Applications. The first time, macOS asks for screen recording and microphone access.
